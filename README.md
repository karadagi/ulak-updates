# Ulak Updates

This public repository is the SideStore update feed for **Ulak**.

- `apps.json` is the AltSource manifest SideStore reads.
- `Ulak.ipa` is the latest unsigned build, signed on-device by SideStore.
- `icon.png` is the public app icon used by the source.

The application source code remains in a separate private repository.

## Add to SideStore

Open this URL on an iPhone with SideStore installed:

`sidestore://source?url=https%3A%2F%2Fraw.githubusercontent.com%2Fkaradagi%2Fulak-updates%2Fmain%2Fapps.json`
